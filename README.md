# @surea11y/pack-en301549

EN 301 549, the European accessibility standard, as a pack for [`@surea11y/core`](https://github.com/SureA11y/core): chapter 9 (Web) in V3.2.1 and V4.1.1, the clause that restates each WCAG criterion, one result per clause, and a profile per version.

Not released yet: the pack is being prepared, and comes with the `@surea11y/core` release that no longer has EN 301 549 built in.
